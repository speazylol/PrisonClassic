# PrisonClassic 4.3 — режим «Prison Classic / Normal»

Плагин для Paper 1.21.4+ (Java 21). Основа — PrisonClassic 3.4.0, доработан по ТЗ.

## Новое в 4.3
- **Мобы сами не спавнятся** — только боссы и мобы плагина (настройка `block-natural-mobs`, в мире выключен `doMobSpawning`).
- **Торговцы на шахтах не пропадают**: жители на дальних островах исчезали при выгрузке чанка, теперь плагин ставит их обратно, как только чанк загружен.
- **/donate — привилегии** VIP, PREMIUM, ELITE, LEGEND, EVO (право `prison.donate.1…5`, выдаётся через LuckPerms после оплаты):
  телепорт быстрее, +монеты/блоки, `/sell` в любой точке (с PREMIUM), `/autosell` (с ELITE), без нужд (с LEGEND),
  личная шахта 20/40/60 мин. в день, ежедневные ключи (кнопка в `/donate`), префикс в чате и табе. Всё — в `config.yml → donate`.
  Магазин за звёзды (ДК, AutoSell_Premium) — кнопка в том же меню.
- **Звёзды** — только предметы (звезда Незера) в инвентаре; старый баланс звёзд при входе выдаётся предметами.
- Команда `/marry` убрана.

## Установка
1. Положите `PrisonClassic-4.2.0.jar` в `plugins/` и запустите сервер.
2. При первом запуске плагин сам создаёт мир `prison_classic` и строит всё: спавн, 23 острова шахт, Тюремный подвал, Базу, камеры, деревню, арену Злого Тыкова и Вампирские катакомбы.
3. Если стоял PrisonClassic 3.x: старый `config.yml` будет сохранён как `config-old.yml`. Пересоберите мир под новые 24 шахты командой `/pa build confirm` (лучше в пустом мире).
4. Спавн (4.2): детальный «Тюремный городок» ~300×300 — см. раздел ниже. Чтобы перестроить его на уже готовом мире, выполните `/pa build confirm`: стройка занимает около 45 секунд (≈12 млн блоков, настройка `build.blocks-per-tick`). Нужна высота: центр мира должен стоять минимум на 49 блоков выше дна мира и на 61 ниже потолка.
5. MySQL (необязательно): `storage.type: mysql` и раздел `storage.mysql` в `config.yml`. Таблицы `prison_players` и `prison_dungeon_records` создаются сами.

## Спавн «Тюремный городок»
Все здания строятся по воксельной сетке с настоящими состояниями блоков: соединённые заборы и стёкла, угловые ступени, ставни, двери, подвесные фонари на цепях.
- **Центр** — круглая площадь Ø64 с узором-розой ветров, трёхъярусный фонтан с подсветкой, две сакуры в клумбах, скамейки, фонари. СЗ — павильон сундуков (3 постамента), СВ — доска заданий с Квестовиком. Точка спавна — у южного края площади.
- **Север** — Столовая (каркасный зал с открытыми стропилами, кухня, длинные столы) и двухэтажная Спальня (50 кроватей, сундуки), обе с крыльцами и слуховыми окнами. В конце дороги — Землянка (шахта 1) с воротами, краном, рельсами и лавкой торговца.
- **Восток** — Санузел: туалетные кабинки (воронки, рычаги, двери), душевые (котлы), умывальники, башенка на коньке. За ним Тренировочный двор: манекены, стрельбище, трибуны, навес Тренера.
- **Запад** — Собор: неф с контрфорсами и витражами, трансепт с розетками, апсида с алтарём, колокольня с часами и шпилем (внутри — кубоид службы).
- **Юг** — Торговая улица: Магазин и лавка Скупщика, Кузница с горном и дымоходом, Донат-храм с колоннадой и куполом, Шатёр Цыгана с повозкой. В конце — Надвратная башня с порталом и Проводником.
- **Юго-восток** — Огород (шахта 2): поля с культурами, амбар торговца, пугало, колодец. СЗ — пруд с причалом, ЮЗ — парк с беседкой, СВ — фруктовый сад.
- По краю — крепостная стена с зубцами, галереей, плющом и 8 круглыми башнями.

## Команды игроков
| Команда | Что делает |
|---|---|
| `/lvl`, `/lvl up` | Меню уровня, повышение (блоки + монеты, фракционная скидка) |
| `/trainer` | Тренер: Ловкость, Удача, Проклятие I–VI, Урон по мобам I–IX, Крит I–V, экономические перки |
| `/up` | Улучшение предмета в руке (редкости, откат/фиксация, уничтожение луков) |
| `/mine`, `/warp` | Шахты и локации (подвал — по пропуску) |
| `/sell`, `/autosell` | Только с флагом **AutoSell_Premium**, без него — отказ в чат |
| `/cell [menu\|upgrade\|buy\|list\|add\|remove\|leave]` | Камера с 8 ур., 4 тира: сито, душ, полка коллекций |
| `/six`, `/sieve` | Тюремная банда (NPC-помощники), сито |
| `/collection` | Коллекции «Наследие Предков» (30 осколков) |
| `/dungeon invite\|accept\|leave\|start\|top` | Вампирские катакомбы (3 игрока, тайм-аттак) |
| `/fw`, `/fw attack <точка>` | Войны Семей (кланов `/gang`) за контрольные точки |
| `/ttt <ник> <сумма>`, `/ttt accept\|deny` | Крестики-нолики на монеты |
| `/auc`, `/auc sell <цена>` | Аукцион (снять свой лот — штраф 10%) |
| `/keys`, `/exchange`, `/donate` | Сундуки, обмены, донат-магазин (ДК = 14 звёзд) |
| `/church`, `/needs`, `/points`, `/gang`, `/family`, `/top`, `/quest` | Церковь, нужды, точки фракций, банда, брак, топы, квесты |

## Права
- `AutoSell_Premium` (или `prison.autosell.premium`) — премиум `/sell` и `/autosell`. Также даётся донат-рангами 4–5 и покупкой у Донат-NPC за звёзды.
- `prison.donate.1` … `prison.donate.5` — донат-ранги.
- `prison.noneeds` — без нужд.
- `prison.admin` — админ-команды `/pa`.

## Админ
`/pa build confirm`, `/pa setloc <ключ>` (church.a/b, basement.a/b, npc.gypsy, npc.donate, npc.dungeon, npc.merchant.<шахта>, sign.merchant.<шахта>, dungeon.room1..3, fpoint.<id>), `/pa boss list|add|remove`, `/pa give special|shard|premium|book|key|stars|kills …`, `/pa reload`.

Вся настройка балансa — в `config.yml`.
